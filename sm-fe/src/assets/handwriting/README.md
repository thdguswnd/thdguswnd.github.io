# 손글씨 카드 이미지

INVITATION 섹션의 손글씨 카드 캐러셀에 쓰이는 이미지 폴더입니다.

## 넣는 방법
- **투명 배경 PNG(또는 WebP)** 로 저장하세요. **JPG는 투명을 지원하지 않으니 사용 금지.**
- 파일명 **번호 순서**대로 사람에 매핑됩니다 (파일명 오름차순):

| 파일 예시 | 사람 |
|---|---|
| `01-송창용.png` | 신랑 아버지 (송창용) |
| `02-오재순.png` | 신랑 어머니 (오재순) |
| `03-송현중.png` | 신랑 (송현중) |
| `04-조진범.png` | 신부 아버지 (조진범) |
| `05-김진.png` | 신부 어머니 (김진) |
| `06-조나영.png` | 신부 (조나영) |

- 앞의 **두 자리 번호(01~06)** 만 맞으면 뒤 이름은 자유입니다. 번호가 순서를 결정합니다.
- 이미지가 없는 자리는 이름 텍스트 카드(placeholder)로 표시됩니다.
- 파일을 넣은 뒤 커밋/푸시하면 자동 반영됩니다.

## 경로별 첫 카드
- 기본(`/`) 첫 카드: **신랑(송현중)** — `HandwritingCarousel.tsx`의 `DEFAULT_START`로 변경 가능
- 링크로 첫 카드 지정(예):
  - `/신랑부` 또는 `/groom-father` → 송창용
  - `/신랑모` `/groom-mother` → 오재순
  - `/신랑` `/groom` → 송현중
  - `/신부부` `/bride-father` → 조진범
  - `/신부모` `/bride-mother` → 김진
  - `/신부` `/bride` → 조나영
- 나머지 순서·내용은 모두 동일하며, 첫 카드만 달라집니다.
