# 손글씨 카드 이미지

INVITATION 섹션의 손글씨 카드 캐러셀에 쓰이는 이미지 폴더입니다.

## 이비스 페인트 X 캔버스
- 비율 **3:4(세로)**, 크기 **1200 × 1600 px**, **투명 배경**, **PNG** 내보내기.
- 카드는 모바일에서 **화면 가로를 꽉 채워** 표시됩니다(대략 340~420px 폭). 캔버스 전체가 이 폭에 맞춰 축소되므로, **캔버스를 채우면 카드도 채워집니다.**
- 모바일 표시 크기 가늠: **모바일 픽셀 ≈ 캔버스 픽셀 × 0.3**. (예: 캔버스에서 글자 높이 ~130px → 모바일 ~40px, 읽기 좋은 크기)
- 해상도(1200×1600)는 **선명도**용일 뿐 글씨 크기와 무관합니다. 글씨를 크게 쓰려면 **줄 수를 줄이고 획을 크게** 쓰세요.

## 넣는 방법
- **투명 배경 PNG(또는 WebP)** 로 저장하세요. **JPG는 투명을 지원하지 않으니 사용 금지.**
- 파일명 **번호 순서**대로 사람에 매핑됩니다 (파일명 오름차순):

| 파일 예시 | 사람 |
|---|---|
| `01-송창용.png` | 신랑 아버지 (송창용) |
| `02-오재순.png` | 신랑 어머니 (오재순) |
| `03-조진범.png` | 신부 아버지 (조진범) |
| `04-김진.png` | 신부 어머니 (김진) |
| `05-송현중.png` | 신랑 (송현중) |
| `06-조나영.png` | 신부 (조나영) |

- 앞의 **두 자리 번호(01~06)** 만 맞으면 뒤 이름은 자유입니다. 번호가 순서를 결정합니다.
- 이미지가 없는 자리는 이름 텍스트 카드(placeholder)로 표시됩니다.
- 파일을 넣은 뒤 커밋/푸시하면 자동 반영됩니다.

## 첫 카드 (현재 랜덤 ON)
- 기본(`/`): 업로드된 카드 중 **접속마다 랜덤** (`HandwritingCarousel.tsx`의 `RANDOM_DEFAULT = true`). 고정하려면 `false` + `DEFAULT_START` 사용.
- 링크로 첫 카드 지정(랜덤보다 우선):
  - `/신랑부` 또는 `/groom-father` → 송창용
  - `/신랑모` `/groom-mother` → 오재순
  - `/신부부` `/bride-father` → 조진범
  - `/신부모` `/bride-mother` → 김진
  - `/신랑` `/groom` → 송현중
  - `/신부` `/bride` → 조나영
- 나머지 순서·내용은 모두 동일하며, 첫 카드만 달라집니다.
