# Requirements — 포켓몬 결혼 배틀

표기: **FR** 기능요구, **NFR** 비기능요구. (v1 = 현재 구현 범위)

## 기능 요구사항 (Functional)

### FR-1 화면/오리엔테이션
- FR-1.1 가로 모드 3:2 화면을 뷰포트 중앙에 레터박스로 표시한다.
- FR-1.2 세로 모드에서는 "휴대폰을 가로로 돌려주세요" 안내를 표시한다.

### FR-2 인트로(이름 묻기)
- FR-2.1 흰 배경에 오박사 스프라이트가 등장한다.
- FR-2.2 하단 대화창에 환영/자기소개/이름질문 대사를 타자기 효과로 순차 표시하고, 터치로 진행한다.
- FR-2.3 이름 질문 후, **대화창 우측 위에 오버랩**되는 선택지 창에 `송현중`, `조나영`을 표시한다.
- FR-2.4 선택은 터치로 한다.

### FR-3 확인(Confirm)
- FR-3.1 송현중 선택 시: "LG CNS에서 인프라 아키텍트로 일하고 있는 송현중이 맞니?"
- FR-3.2 조나영 선택 시: "크레아 스튜디오에서 PD로 일하고 있는 조나영이 맞니?"
- FR-3.3 `네` → 배틀로 진행. `아니오` → 이전(이름 선택) 화면으로 복귀.

### FR-4 배틀 진입
- FR-4.1 송현중: "야생의 예비 신부가 배틀을 신청했다!" → "나와라 잉어킹!" (잉어킹 소환)
- FR-4.2 조나영: "야생의 예비 신랑이 배틀을 신청했다!" → "나와라 밴드왕!" (거북왕 모양 밴드왕 소환)
- FR-4.3 상대 포켓몬은 우측 상단, 아군 포켓몬은 좌측 하단에 배치(레드 배틀 레이아웃).

### FR-5 전투(기술 메뉴)
- FR-5.1 하단에 2x2 기술 메뉴: `신혼집`, `신혼여행`, `미정`, `미정`.
- FR-5.2 기술 선택 시 아군이 공격 연출(돌진→상대 흔들림)을 하고 상대 HP가 **25%** 감소한다.
- FR-5.3 사용한 기술은 **비활성화**되어 재선택 불가.
- FR-5.4 4개 기술을 모두 한 번씩 사용하면 상대 HP가 0%가 되어 **승리**한다.
- FR-5.5 '미정'은 아직 미정 항목이므로 placeholder 대사만 나오며, 추후 실제 항목으로 교체한다.

### FR-6 승리
- FR-6.1 상대가 쓰러지는 연출 + 승리/축하 대사.
- FR-6.2 마지막에 "청첩장 보러가기" CTA(사이트 루트 링크)를 제공한다.

## 비기능 요구사항 (Non-Functional)
- NFR-1 **정적 전용**: 백엔드/DB/빌드 없이 파일 서빙만으로 동작(`file://` 및 GitHub Pages).
- NFR-2 **배포 경로**: `thdguswnd.github.io/pokemon` 하위 경로에서 동작(상대 경로 자산).
- NFR-3 **호환성**: 모던 모바일 브라우저(iOS Safari/Android Chrome). ES5 호환 클래식 스크립트.
- NFR-4 **저작권**: 실제 게임 에셋 미사용, 오리지널 SVG 오마주 아트만 사용.
- NFR-5 **폰트**: 한글 도트 폰트(Galmuri) CDN 로드, 실패 시 monospace 폴백.
- NFR-6 **접근성/입력**: 터치 우선, 탭 하이라이트/확대 억제, 커서 애니메이션으로 선택 피드백.
