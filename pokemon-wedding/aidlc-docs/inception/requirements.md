# Requirements — 포켓몬 결혼 배틀

표기: **FR** 기능요구, **NFR** 비기능요구. (v1 = 현재 구현 범위)

## 기능 요구사항 (Functional)

### FR-1 화면/오리엔테이션
- FR-1.1 가로 3:2 화면을 뷰포트 중앙에 레터박스로 표시한다.
- FR-1.2 **강제 회전 안내를 두지 않는다.** 세로 뷰포트(회전잠금 사용자 포함)에서는 게임 화면을
  CSS로 90° 회전시켜 항상 가로로 보이게 한다(사용자는 폰만 옆으로 들면 정상 화면).
  가로 뷰포트에서는 회전 없이 그대로 렌더한다.
- FR-1.3 화면 크기는 **`visualViewport`(브라우저 주소줄을 제외한 실제 가시영역)** 기준으로 계산해
  주소줄에 의해 잘리지 않게 한다. `resize`/`orientationchange`/`visualViewport` 이벤트마다 재계산한다.
  (CSS 폴백은 `dvh/dvw`.)

### FR-2 인트로(이름 묻기)
- FR-2.1 흰 배경에 오박사 스프라이트가 등장한다.
- FR-2.2 하단 대화창에 환영/자기소개/이름질문 대사를 타자기 효과로 순차 표시하고, 터치로 진행한다.
- FR-2.3 이름 질문 후, **대화창 우측 위에 오버랩**되는 선택지 창에 `송현중`, `조나영`을 표시한다.
- FR-2.4 선택은 터치로 한다.

### FR-3 확인(Confirm)
- FR-3.1 송현중 선택 시: "LG CNS에서 인프라 아키텍트로 일하고 있는 송현중이 맞니?"
- FR-3.2 조나영 선택 시: "크레아 스튜디오에서 PD로 일하고 있는 조나영이 맞니?"
- FR-3.3 `네` → 배틀로 진행. `아니오` → 이전(이름 선택) 화면으로 복귀.

### FR-4 배틀 진입 (포켓몬 없이 트레이너끼리)
- FR-4.1 확인 '네' 후 오박사 반응 대사(postConfirm) → 배틀 전환 연출.
- FR-4.2 배틀 인트로: "{상대}에게 궁금한 걸 물어보자!" (상대=신부 조나영/신랑 송현중).
- FR-4.3 상대(=상대편 인물)는 우측 상단, 나는 좌측 하단(뒷모습)에 배치. 포켓몬은 없다.

### FR-5 전투(질문 Q&A)
- FR-5.1 하단 = 좌 프롬프트 + 우 2x2 보기: `신혼집 어디야?`, `신혼여행 어디가?`, `밴드왕이 뭐야?`, `도망친다`.
- FR-5.2 질문 선택 시: 내가 물음(내 캐릭터 돌진, 공격) → 상대가 답함(상대 캐릭터 돌진, 반격). 답변은 여러 줄일 수 있다.
- FR-5.3 체력 감소는 **인물 기준**: 송현중은 한 번에 1/3(3대=0), 조나영은 1/6(6대=0).
  - 내가 질문할 때 상대가 감소, 상대가 답할 때 내가 감소.
- FR-5.4 사용한 질문은 **비활성화**. `도망친다`는 항상 선택 가능.

### FR-6 종료/엔딩
- FR-6.1 질문 3개로 **송현중 체력이 0**이 되면 송현중 캐릭터가 아래로 사라지며 "준비된 질문이 끝났다!" → 엔딩.
- FR-6.2 `도망친다` 선택 시: 나(좌하)가 왼쪽으로 사라지며 "질문을 그만두고 도망쳤다!" → 엔딩.
- FR-6.3 엔딩: 화면 하얗게 → 신랑(송현중)·신부(조나영)가 양쪽에서 가운데로 나란히 → 마무리 인사.
- FR-6.4 대화창 우측에 가로 팝업 `다시 시작 / 끝내기`. 다시 시작=처음부터, 끝내기=창 종료.

## 비기능 요구사항 (Non-Functional)
- NFR-1 **정적 전용**: 백엔드/DB/빌드 없이 파일 서빙만으로 동작(`file://` 및 GitHub Pages).
- NFR-2 **배포 경로**: `thdguswnd.github.io/pokemon` 하위 경로에서 동작(상대 경로 자산).
- NFR-3 **호환성**: 모던 모바일 브라우저(iOS Safari/Android Chrome). ES5 호환 클래식 스크립트.
- NFR-4 **저작권**: 실제 게임 에셋 미사용, 오리지널 SVG 오마주 아트만 사용.
- NFR-5 **폰트**: 한글 도트 폰트(Galmuri) CDN 로드, 실패 시 monospace 폴백.
- NFR-6 **접근성/입력**: 터치 우선, 탭 하이라이트/확대 억제, 커서 애니메이션으로 선택 피드백.
