# Intent — 포켓몬 결혼 배틀

## 한 줄 의도
청첩장을 찾은 하객이 **옛날 포켓몬스터 레드풍 미니게임**을 잠깐 플레이하며,
신랑/신부를 골라 "배틀"에서 승리하는 재미로 결혼 소식을 즐겁게 전한다.

## 배경
- 기존 모바일 청첩장(`thdguswnd.github.io`, `sm-fe` Vite+React)의 **하위 페이지 `/pokemon`** 로 추가.
- 별도의 백엔드/DB 없이 **완전 정적**으로 동작해야 한다(비용 0, 유지보수 최소).

## 타깃 & 사용 맥락
- 대상: 결혼식 하객(모바일 사용자).
- 기기: 스마트폰을 **가로로 든** 상태(레드/GBA 화면비 3:2).
- 입력: **터치만**(데스크톱은 클릭). 키보드 불필요.

## 성공 기준 (v1)
1. 흰 화면 + 오박사가 이름을 묻고, 우측 상단 오버랩 선택지로 송현중/조나영 선택.
2. 각 인물에 맞는 확인 질문 → '네' 진행 / '아니오' 복귀.
3. 배틀 진입 문구 + 아군 소환 문구가 인물별로 정확.
4. 4개 기술(신혼집/신혼여행/미정×2)을 한 번씩 쓰면 상대 HP 25%씩 감소 → 0% 승리.
5. 세로로 들면 "가로로 돌려주세요" 안내.

## 명시적 비목표 (Out of Scope, v1)
- 상대의 반격/데미지(아군 HP는 100% 고정).
- 저장/랭킹/공유, 사운드(추후 디벨롭 여지로 남김).
- 실제 포켓몬 저작권 에셋 사용(전부 오리지널 오마주 아트).

## 참고: 캐릭터 설정
- 송현중: 마곡 LG CNS 인프라 아키텍트 (신랑).
- 조나영: 홍대 크레아 스튜디오 PD (신부).
- 배틀은 포켓몬 없이 두 사람(트레이너)끼리 Q&A로 진행한다.
