# 포켓몬 결혼 배틀 — 작업 로그 & 참고 문서

> 이 문서는 프로젝트 전체를 한눈에 파악하기 위한 참고용 요약이다.
> 상세 산출물은 [`aidlc-docs/`](aidlc-docs/), 실행 코드는 [`src/`](src/) 에 있다.
> 최종 갱신: 2026-08-18

---

## 1. 개요
- **무엇**: 옛날 포켓몬스터(FRLG풍) UI의 결혼 청첩장 미니게임.
- **어디에**: 기존 모바일 청첩장 `thdguswnd.github.io` 의 하위 경로 `/pokemon`.
- **특징**: 백엔드/DB 없음(완전 정적), 터치 조작, 가로 3:2 화면, 세로로 들면 자동 90° 회전.
- **컨셉**: 오박사가 하객을 맞이 → 신랑/신부 선택 → "궁금한 걸 물어보는" 배틀 → 엔딩(결혼식 인사).

---

## 2. 게임 흐름 (현재 최종 스펙)

### (1) 인트로 — 오박사
- 배경: 민트 그라데이션 + 지평선 + 타원 발판. 오박사가 fade-in.
- 대사(순차, 대화창 클릭으로 진행):
  1. `안녕!`
  2. `두 사람의 결혼식에 온 걸 / 진심으로 환영한다!`
  3. `그럼 먼저 주인공들에 대해 / 알아보자꾸나!`
- 이후 오박사 fade-out(배경 유지) → 질문 `너는 신랑인가? / 그게 아니면 신부인가?`
- 우측 상단 선택창: **`송현중(신랑)`** / **`조나영(신부)`** (터치 선택)

### (2) 확인
- 선택 인물의 정면 이미지가 fade-in + 확인 대사:
  - 송현중: `마곡에 있는 LG CNS에서 인프라 아키텍트로 / 일하고 있는 송현중이 맞니?`
  - 조나영: `홍대에 있는 크레아 스튜디오에서 PD로 / 일하고 있는 조나영이 맞니?`
- **네** → 오박사 반응 대사(postConfirm) → 배틀 전환
  - 송현중: `IT쪽 일을 하지만 개발자는 아니고, 개발자들이 일할 수 있게` / `클라우드, 서버 같은 걸 구성해 주는 일을 하는구나!` / `무슨 말인지 모르겠지만 궁금하지는 않다!`
  - 조나영: `한일가왕전, 한일로맨스 혼전연애, 쉬는부부, 불타는 장미단 등` / `여러 프로그램에 PD로 참여했구나! 근사하다!`
- **아니오** → 인물 fade-out → 다시 신랑/신부 선택으로

### (3) 배틀 전환 연출 (원작 오마주)
1. 회색 화면 2회 깜빡임
2. 바깥→안쪽으로 검은색 블랙아웃
3. 가운데 가로선에서 위아래로 배틀 화면 열림
4. 배경에 파란 가로 스트릭이 우→좌로 흐름
5. 트레이너 슬라이드: 상대(좌상→우상), 나(우하→좌하)

### (4) 배틀 — 포켓몬 없이 트레이너끼리 Q&A
- 인트로 문구: `{상대}에게 궁금한 걸 물어보자!` (예: 신부 조나영에게 / 궁금한 걸 물어보자!)
- 화면: 상대(우상, 정면) / 나(좌하, 뒷모습), 양쪽 HP 박스.
- 하단 명령 바 = **좌: 프롬프트 `무엇을 물어볼까?`** + **우: 2x2 보기**
- 보기 4개:
  | 보기 | 내가 물음(공격) | 상대가 답함(반격, 여러 줄) |
  |---|---|---|
  | **신혼집 어디야?** | {나}은/는 신혼집을 어디에 구했는지 물어봤다! | {상대} 작고 귀여운 신혼집을 강서구 9호선 가양역 근처에 구했다고 답했다! |
  | **신혼여행 어디가?** | {나}은/는 신혼여행을 어디 가는지 물어봤다! | ① 방송이 있어서 신혼여행은 내년 3~4월쯤 갈 계획 ② 결혼식 끝나고 오키나와 짧게 다녀오고 싶다 |
  | **밴드왕이 뭐야?** | {나}은/는 밴드왕이 뭐냐고 물어봤다! | ① 'SBS 한일 밴드 오디션 밴드왕'은 신부가 준비 중인 방송 ② 한·일 뮤지션들이 국경·장르·나이·경력·성별을 뛰어넘어 ③ 단 하나의 한일 밴드를 만드는 음악 서바이벌 ④ 많관부! |
  | **도망친다** | (공격 아님) 나(좌하)가 왼쪽으로 사라짐 + `질문을 그만두고 도망쳤다!` → 엔딩 | — |
- 질문 1회당 상대 궁금증(HP) 감소: **100 → 67 → 33 → 0**. 사용한 질문은 비활성화.
- 조사(은/는·을/를)는 이름 받침에 따라 자동 처리(`data.js`의 `josa`).

### (5) 엔딩 (배틀 다음 화면)
1. 화면 하얗게 fade
2. 신랑(송현중, 좌)·신부(조나영, 우)가 양쪽에서 가운데로 모여 나란히
3. 대사: `자세한 얘기는 / 만나서 들려드릴게요!` → `결혼식날 뵙겠습니다. / 감사합니다!`
4. 작은 팝업: **재시작 / 종료**
   - **재시작**: 게임 처음부터 (`location.reload()`)
   - **종료**: 창 닫기(`window.close()`). 청첩장에서 새 창으로 열렸을 때만 동작하며, 실패 시 청첩장 루트(`../`)로 이동.

## 3. 파일 구조
```
pokemon-wedding/
├── WORKLOG.md                 ← (이 문서)
├── README.md                  ← 빠른 소개/실행
├── aidlc-docs/                ← AI-DLC 산출물
│   ├── aidlc-state.md         ← 상태 추적 + 버전별 검증 로그(v1~v5)
│   ├── inception/{intent,requirements}.md
│   └── construction/
│       ├── design/{game-flow,ui-spec,data-model}.md
│       └── plans/implementation-plan.md
└── src/                       ← 실행 코드(정적, 빌드 불필요)
    ├── index.html
    ├── styles/game.css
    ├── scripts/
    │   ├── data.js            ← 대사/보기/캐릭터/조사 헬퍼 (window.GAME_DATA)
    │   ├── sprites.js         ← 오리지널 SVG 폴백 (window.GAME_SPRITES)
    │   └── game.js            ← 상태 머신 + 연출 + 입력
    └── assets/                ← 사용자 제공 PNG (README 참고)
```

## 4. 콘텐츠(대사) 수정 위치
- 모든 대사/보기 텍스트: **`src/scripts/data.js`**
  - `INTRO_LINES`, `CHARACTERS[k].confirmText / postConfirm / battleIntro`,
    `MOVES[].ask/answer`, `ENDING_LINES`, `BATTLE_PROMPT`
- 연출 속도/타이밍: `data.js`의 `CONFIG`(typeSpeedMs 등) + `game.js` 내 setTimeout 값
- 그림: `src/assets/*.png` (없으면 `sprites.js` SVG 폴백)

## 6. 실행 & 배포
### 로컬 실행
```bash
npx --yes serve pokemon-wedding/src
```
또는 `src/index.html` 직접 열기. 데스크톱은 창을 가로로 넓게(세로면 자동 회전).

### 배포 (thdguswnd.github.io/pokemon)
GitHub Actions가 `sm-fe`를 빌드하며 `sm-fe/public/` 를 그대로 배포한다. 게임을 `public/pokemon/`에 복사하면 `/pokemon` 경로로 서빙된다.
```bash
cd /c/AIDLC_WS_GREEN
rm -rf sm-fe/public/pokemon
mkdir -p sm-fe/public/pokemon
cp -r pokemon-wedding/src/* sm-fe/public/pokemon/
git add sm-fe/public/pokemon pokemon-wedding
git commit -m "feat(pokemon): 미니게임 갱신"
git push origin main
```
푸시 후 GitHub **Actions** 초록불이면 완료(1~2분). 접속: https://thdguswnd.github.io/pokemon/

## 7. 기술 노트
- 가로 3:2 화면을 `visualViewport`(주소줄 제외) 기준으로 JS가 크기 계산 → 주소줄 잘림 방지.
- 세로 뷰포트면 `#screen`을 90° 회전 → 회전잠금 사용자도 폰만 옆으로 들면 정상.
- fade/전환은 `requestAnimationFrame` 대신 `setTimeout` 사용(비표시 탭에서도 안정).
- 이미지 렌더는 `<img>` 우선, 로드 실패 시 SVG 폴백(`renderSprite`).
- 폰트: Galmuri(도트 한글, jsdelivr) + monospace 폴백.
