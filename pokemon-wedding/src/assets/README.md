# assets/ — 캐릭터 스프라이트 넣는 곳

여기에 아래 파일명으로 PNG(투명 배경 권장)를 넣으면 게임에 그대로 반영됩니다.
**파일이 없으면** 코드가 자동으로 오리지널 도트 대체 그림(sprites.js)을 표시합니다.
(실제 게임 스프라이트는 저작권 자산이므로 저장소에 포함하지 않습니다. 개인용으로 직접 넣어 사용하세요.)

| 파일명 | 용도 | 방향 |
|---|---|---|
| `oak.png` | 오박사 (인트로) | 정면 |
| `song-front.png` | 송현중 (신랑) | 정면 — 확인 화면 & 조나영이 나일 때 상대(우상) |
| `song-back.png` | 송현중 (신랑) | 뒷모습 — 내가 송현중일 때 나(좌하) |
| `jo-front.png` | 조나영 (신부) | 정면 — 확인 화면 & 송현중이 나일 때 상대(우상) |
| `jo-back.png` | 조나영 (신부) | 뒷모습 — 내가 조나영일 때 나(좌하) |

### 포켓몬 (배틀 화면, 트레이너가 내보낸 뒤)
| 파일명 | 용도 | 방향 |
|---|---|---|
| `charmander-back.png` | 파이리 (송현중) | 뒷모습 — 내가 송현중일 때 내 포켓몬(좌하) |
| `charmander-front.png` | 파이리 (송현중) | 정면 — 내가 조나영일 때 상대 포켓몬(우상) |
| `bandwang-back.png` | 밴드왕(거북왕, 조나영) | 뒷모습 — 내가 조나영일 때 내 포켓몬(좌하) |
| `bandwang-front.png` | 밴드왕(거북왕, 조나영) | 정면 — 내가 송현중일 때 상대 포켓몬(우상) |

## 매핑 요약 (트레이너 → 포켓몬)
- 내가 **송현중**: 트레이너 나=`song-back`, 상대=`jo-front` → 포켓몬 나=`charmander-back`(파이리), 상대=`bandwang-front`(밴드왕)
- 내가 **조나영**: 트레이너 나=`jo-back`, 상대=`song-front` → 포켓몬 나=`bandwang-back`(밴드왕), 상대=`charmander-front`(파이리)

> 첨부하신 파이리(송현중)·거북왕(조나영) 스프라이트를 위 파일명으로 저장해 넣으면 됩니다.

## 팁
- 전투 상대(우상, 정면)는 왼쪽을 보게, 내 뒷모습(좌하)은 오른쪽을 보게 만든 스프라이트가 자연스럽습니다.
- 파일명만 맞으면 코드 수정 없이 반영됩니다. 경로는 `data.js`의 `frontImg/backImg/oppImg`에서 바꿀 수 있습니다.
